About Me

I'm currently preparing for university and hoping to study Computer Engineering. My main interests are embedded systems, robotics and the way software can be used to control real hardware.

Most of what I've learned outside the classroom has come from projects. I've worked with ESP32 and Arduino boards, sensors, relays, motors and web interfaces. I especially enjoy projects where I can see the code I write turning into something physical.

I'm still learning, so I don't see my projects as finished products. I like finding the parts that don't work, understanding why, and improving them. That's probably the part of engineering I enjoy the most.

What I'm interested in: Embedded Systems · Robotics · IoT · Electronics · Programming
